# Эксперимент Seasons 4.1.1

[English](README.md) · [Общая инструкция](../BUILD_RU.md)

Отдельный мост старого интерфейса JNI `MyRenderer`/`MyLegacyRenderer`. Поместите оригинальный APK **4.1.1** в локальный `input/`. Эксперимент входит в полный репозиторий и использует общие `../third_party/` и `../tools/wheels/`.

Подготовьте общие инструменты из корня по основной инструкции, затем:

```bash
cd 4.1.1
python tools/release.py --tools ../../toolchains --jobs 4
```

Дефолтный путь инструментов также `../../toolchains`. Результаты и отчёты создаются внутри эксперимента. По умолчанию: пользовательский пакет `com.rovio.angrybirdsseasons.port411`, сохранение входного пакета выключено, исходные названия/значки сохраняются, высота рендера 0, ограничение 60 кадров/с, сетевое разрешение удаляется. Этапа SelectableFixes нет. `--package-only` требует локально собранного подходящего моста. `tools/make_source_archive.py` создаёт архив полного репозитория с общими зависимостями.

Совместимость движка и игрового процесса экспериментальная. Проверка двух входов этого комплекта относится к 6.6.2; проверка 4.1.1 на устройстве не заявляется. См. общие [компоненты](../PROVENANCE_RU.md), [параметры](../docs/SETTINGS_RU.md) и [план устройства](../docs/DEVICE_TESTING_RU.md).

# Тесты конфигурации

[English](README_EN.md)

Из корня соответствующего проекта выполните `python -m unittest discover -s tests -v`. Проверяются конфиги, исходные/пользовательские названия и пакеты, переопределения файлов и выбор итоговых артефактов. Основные тесты также проверяют фиксы по умолчанию и `.fixed`. Образцы — небольшие бинарные манифесты, не полные APK игры. Проверки поведения и сборки описаны в `docs/VERIFICATION_RU.md` корня репозитория.

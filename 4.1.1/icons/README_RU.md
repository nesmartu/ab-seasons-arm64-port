# Пользовательские PNG-значки

[English](README_EN.md)

`icons.custom=false` сохраняет оригинальные значки. При `true` положите сюда общий `icon.png` либо повторите путь существующего ресурса, например `res/drawable-hdpi/icon.png`. Точный путь имеет приоритет над общим PNG. Меняются только существующие drawable/mipmap-пути с окончанием `/icon.png`; неизвестные пути отклоняются. Новые ID и адаптивные XML-значки не создаются. `icons.directory` отсчитывается от корня соответствующего проекта либо задаётся абсолютно.

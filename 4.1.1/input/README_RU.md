# Входной APK

[English](README_EN.md)

Поместите сюда собственный оригинальный APK Angry Birds Seasons 4.1.1. APK не включены и не отслеживаются. Не подставляйте другую версию игры. Сохранения и скачанные инструменты сюда не кладите.

Команда release основного проекта/4.1.1 обрабатывает только непосредственные `*.apk`. Имя произвольное; `--apk /path/to/game.apk` выбирает файл вне этой папки.

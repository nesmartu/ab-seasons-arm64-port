# Параметры сборки

[English](SETTINGS_EN.md) · [Сборка](../BUILD_RU.md)

По умолчанию читается `build_config.toml`; `--config` выбирает другой файл. Пути значков основного проекта и 4.1.1 отсчитываются от корня соответствующего проекта, даже если конфиг лежит отдельно. Пути отдельного патчера отсчитываются от папки выбранного конфига. Пути командной строки — от текущей папки. Логические значения TOML: `true`/`false`.

| Ключ | Значение по умолчанию / поведение |
|---|---|
| `app.preserve_original_package` | `false`; `true` берёт пакет из манифеста и отменяет пользовательские и автоматические суффиксы |
| `app.package` | `com.rovio.angrybirdsseasons.port`; точный пользовательский ID при выключенном сохранении пакета |
| `app.package_mode` | `version`; работает лишь при выключенном сохранении и пустом пользовательском пакете; альтернатива `base` |
| `app.package_base` | `com.rovio.seasonsport.unofficial`; цифры версии вставляются перед `.unofficial` |
| `app.preserve_original_name` | `true`; сохраняет названия приложения/активностей и локализации |
| `app.name` | `Angry Birds Seasons`; используется только при выключенном сохранении имени |
| `icons.custom`, `icons.directory` | `false`, `icons`; [раскладка PNG](../icons/README_RU.md) |
| `bridge.render_height` | `1080`, диапазон 0..8192; 0 использует высоту устройства |
| `bridge.max_fps` | `60`, диапазон 0..1000; 0 отключает ограничение |
| `bridge.allow_network` | `false`; удаляет INTERNET, `true` сохраняет |
| `selectable_fixes.enabled` | `true`; проверено только на 6.6.2, для других совместимых движков выключите |
| `selectable_fixes.append_fixed` | `false`; суффикс лишь для автоматического ID, если патчер и выбранные фиксы включены |
| `selectable_fixes.coins_amount` | `1000000`, диапазон 1..16000000 |
| `fixes.unlock_all_episodes` | `true`; только доступ к эпизодам |
| `fixes.unlock_ragnahog_levels` | `true`; 25 обычных календарных уровней, исходные условия яиц/бонусов |
| `fixes.quest_video` | `true`; кнопка сразу показывает подсказку уровня квеста |
| `fixes.unlock_all_levels` | `false`; все локальные уровни/яйца/бонусы, также открывает эпизоды |
| `fixes.unlocked_all_with_coins` | `false`; эпизоды + однократное пополнение до минимума монет |
| `fixes.cosmetics` | `false`; все 108 предметов Bird Wear |

`unlocked_all_with_coins` не включает полное открытие уровней. Больший баланс сохраняется; маркер в сохранении исключает повторную выдачу, расходование работает обычно. Цели квестов и другие видео с наградой не обходятся. Выключенные флаги сохраняют изменения входа и записанные выдачи. При `enabled=false` или всех выключенных флагах патчер пропускается.

Секции `[variants."game.apk"]` переопределяют только ключи `[app]` по полному исходному имени файла. Название файла не определяет пакет по признакам unlocked/money. Для параллельной установки задайте разные ID. `preserve_original_package=true` может конфликтовать с установленной игрой, подписанной Rovio: у порта другой сертификат. Сохранения между пакетами автоматически не переносятся.

Совместимые псевдонимы: `ragnahog` означает `unlock_ragnahog_levels`; `unlocked_all=true` включает широкое `unlock_all_levels`. Одновременные конфликтующие старый и новый ключи отклоняются. Используйте явные актуальные имена. Псевдонимы нужны для совместимости конфигов и не определяют настройки по умолчанию.

Конфиг `4.1.1/` не содержит выбираемых фиксов, использует `.port411` и высоту рендера 0. Остальные общие параметры имеют описанный выше смысл.

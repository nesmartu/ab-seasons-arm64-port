# ab-seasons-arm64-port

[English](README_AI_EN.md) · [Сборка](BUILD_RU.md) · [Компоненты и лицензии](PROVENANCE_RU.md)

Неофициальная адаптация ARM32-движка Angry Birds Seasons для Android ARM64 через Dynarmic. Основной проект рассчитан на Seasons 6.6.2. Отдельный эксперимент `4.1.1/` использует другой мост и интерфейс JNI.

Поместите собственный оригинальный APK в `input/`. APK игры, её ресурсы и ARM64-библиотеки со встроенным игровым движком не включены: движок извлекается и встраивается локально при сборке. Требования к компьютеру: Linux x86_64, Python 3.11+, Java 17. Результат: Android API 26+, `arm64-v8a`, targetSdk 28.

```bash
python3 -m venv ../seasons-venv
source ../seasons-venv/bin/activate
python -m pip install -r requirements.txt
python tools/setup_toolchain.py --tools ../toolchains
# Сначала поместите оригинальный APK 6.6.2 в input/.
python tools/release.py --tools ../toolchains --jobs 4
```

По умолчанию перед компиляцией порта применяются доступ к эпизодам, исправление календаря Ragnahog и получение подсказки квеста по кнопке видео. Монеты, косметика и полное открытие уровней выключены. Пакет: `com.rovio.angrybirdsseasons.port`; названия и значки оригинала сохраняются. Сохранение пакета входного APK и `.fixed` выключены. Высота рендера 1080, ограничение 60 кадров/с, разрешение INTERNET удаляется. См. [параметры](docs/SETTINGS_RU.md) и `build_config.toml`.

| Конфигурация в `configs/` | Изменения игры |
|---|---|
| `original.toml` | Без выбираемых фиксов |
| `unlocked_ragnahog_quest.toml` | По умолчанию: эпизоды + Ragnahog + подсказки квестов |
| `unlocked_money_ragnahog_quest.toml` | То же + однократное пополнение до минимума монет |
| `unlocked_money_ragnahog_quest_cosmetics.toml` | То же + все 108 предметов Bird Wear |
| `unlocked_money_ragnahog_quest_cosmetics_alllevels.toml` | То же + все локальные уровни, яйца и бонусы |

Например, добавьте `--config configs/original.toml`. Все конфигурации используют одинаковый пакет по умолчанию и публичный ключ разработки, поэтому заменяют друг друга. Идентификатор пакета и криптографический сертификат — разные вещи; исходным сертификатом Rovio изменённый APK подписать нельзя.

`unlock_all_episodes` сохраняет обычное прохождение и условия яиц, звёзд и перьев. `unlock_ragnahog_levels` открывает 25 обычных календарных уровней Ragnahog, сохраняя условия трёх бонусных уровней/яиц. `unlock_all_levels` явно обходит локальные ограничения уровней, яиц и бонусов; очки не начисляет, отсутствующий сетевой контент не восстанавливает. Выключенные фиксы не отменяют уже внесённые изменения и записанные открытия.

`SelectableFixes/` работает и отдельно, создавая ARM32 APK. Фиксы поддерживают только 6.6.2. Проверки ELF, импортов, релокаций и JNI сохранены; привязки к хешу всего APK или имени файла нет. Для другого движка может потребоваться доработка моста.

Структура: `bridge/` — мост и генерируемые вспомогательные данные; `third_party/` — общие зависимости; `tools/` — компиляция, упаковка и аудит; `configs/` — конфигурации; `tests/` — проверки настроек; `SelectableFixes/` — патчер и тесты; `4.1.1/` — эксперимент со старым движком. Генерируемые `build/`, `dist/`, `reports/` игнорируются и не включаются в архив исходников.

См. [проверки](docs/VERIFICATION_RU.md) и [проверку на устройстве](docs/DEVICE_TESTING_RU.md). Успешная автоматическая сборка не подтверждает установку и игровую совместимость. Лицензии и уведомления компонентов сохранены на исходных языках; инструкции проекта доступны на русском и английском.

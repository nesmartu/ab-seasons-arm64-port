# Входной APK

[English](README_EN.md)

Поместите сюда собственный оригинальный APK Angry Birds Seasons 6.6.2. APK не включены и не отслеживаются. Не подставляйте другую версию игры. Сохранения и скачанные инструменты сюда не кладите.

Дефолтный конфиг ожидает `AngryBirdsSeasons_v6.6.2.apk`. Для другого имени используйте `--input /path/to/game.apk` или измените `build.input` конфига патчера.

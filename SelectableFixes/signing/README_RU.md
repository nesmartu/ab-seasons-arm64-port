# Публичный ключ разработки ARM32

[English](README_EN.md)

`test-key.pem` и `test-cert.pem` — намеренно публичная пара RSA для результатов отдельного патчера. Она отличается от ключа итогового ARM64-порта и не является сертификатом Rovio. Для собственного выпуска задайте другой ключ/сертификат через `[build].key`/`cert`; закрытые ключи в git не добавляйте. Патчер сохраняет исходный пакет, поэтому установка поверх оригинального APK с другим сертификатом не является обновлением на месте.

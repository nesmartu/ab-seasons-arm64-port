# Модули фиксов

[English](README_EN.md)

`apply(ctx, options)` каждого модуля меняет только выбранные ресурсы/прототипы. Общие разбор и запись находятся в `common.py`; порядок и область описаны в [RESEARCH](../RESEARCH_RU.md). `unlock_all_levels` и `coins` включают отдельный патч эпизодов через маршрутизацию сборки, а не вызовом другого модуля. `logic_reference.lua` объясняет логику и не компилируется в игру.

# Input APK

[Русский](README_RU.md)

Place your own original Angry Birds Seasons 6.6.2 APK here. APKs are not included or tracked. Do not substitute a different game version. Do not put saves or toolchain downloads in this folder.

The main/4.1.1 release command processes direct `*.apk` files only. Filenames are unrestricted; `--apk /path/to/game.apk` selects a file elsewhere.
